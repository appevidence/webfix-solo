# Code of Conduct

This project follows the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

Reports of unacceptable behavior may be sent privately via GitHub's
["Report content"](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam) flow,
or by opening a security advisory on this repository.
